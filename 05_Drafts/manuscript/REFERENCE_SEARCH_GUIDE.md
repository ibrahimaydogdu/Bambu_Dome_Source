# Reference search guide

Each `[REF-S#]` in the manuscript marks a statement that needs a source. The table says what the statement is, where to search, with which keywords, what kind of source to look for, and what to check. No bibliographic detail is given from memory; take the citation from the source itself. When a source is found, replace the placeholder with a numbered citation: add the entry to the reference list and put `[n]` at the end of the sentence.
